# @fonts.mv/web

The fonts.mv site: SvelteKit 3 on a Cloudflare Worker (static assets for pages and fonts, Worker routes for the `/css2` API and `/downloads` from R2).

```sh
pnpm dev            # from the repo root: builds packages first
pnpm build && pnpm preview   # the real Worker under wrangler dev, port 4173
pnpm test:e2e       # Playwright against the preview
```

Fonts in `static/fonts` and `src/lib/data` are generated by `fonts/scripts/build.py`. Don't edit them by hand; CI rebuilds and compares.
